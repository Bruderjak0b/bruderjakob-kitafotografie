Einbauen

Apple Mail

  1. Oben auf Signatur kopieren klicken. Falls der Browser das Kopieren blockiert: Die Signatur wird stattdessen markiert, dann Cmd + C drücken.
  2. In Mail: Mail → Einstellungen → Signaturen.
  3. Links das Postfach wählen, unten auf + klicken, die neue Signatur benennen.
  4. Im rechten Feld den vorgeschlagenen Text löschen und mit Cmd + V einfügen.
  5. Wichtig: Das Häkchen bei „Immer an Standardschriftart anpassen“ entfernen, sonst wirft Mail die Formatierung weg.
  6. Unter Signatur auswählen die neue Signatur als Standard setzen.

Outlook für Mac

  1. Signatur kopieren wie oben.
  2. Outlook → Einstellungen → Signaturen, auf + klicken.
  3. In das Bearbeitungsfeld einfügen und speichern.
  4. Unter Standardsignatur für neue Nachrichten und für Antworten auswählen.

Outlook für Windows

  1. Signatur kopieren wie oben.
  2. Datei → Optionen → E-Mail → Signaturen, Neu wählen.
  3. Einfügen mit Strg + V. Wenn das Logo fehlt: im Editor auf Bild einfügen klicken und die Datei bilder/logo-signatur.png aus diesem Ordner wählen.
  4. Rechts oben für Neue Nachrichten und Antworten/Weiterleitungen auswählen.

Webmail bei IONOS, Gmail und ähnlichen

Dort gibt es meist ein Feld „Signatur“ mit einem kleinen Editor. Das Einfügen funktioniert genauso. Manche Webmailer erlauben keine eingebetteten Bilder, dann bleibt das Logo leer. In dem Fall die Kurzvariante ohne Logo nehmen.

Gut zu wissen

  • Das Logo hängt als kleiner Anhang an jeder Mail (rund 12 KB). Manche Programme zeigen deshalb eine Büroklammer an der Nachricht. Das ist normal und lässt sich bei eingebetteten Bildern nicht vermeiden.
  • Einige Empfänger sehen das Logo erst nach einem Klick auf „Bilder laden“. Alle wichtigen Angaben stehen deshalb als Text darunter, nicht im Bild.
  • Nichts wird nachgeladen. Das Logo steckt direkt in der Signatur, es gibt keinen externen Aufruf und damit kein Tracking der Empfänger.
  • Keine Telefonnummer doppelt. Wenn du in einer Mail schon eine Nummer nennst, reicht die Signatur darunter.
  • Antwortverläufe: Bei langen Verläufen die Kurzvariante nehmen, sonst sammeln sich mehrere Logos in einer Mail.

Ändern

Adresse, Nummer oder Links ändern sich? Diese Datei bearbeiten (signatur.html), die Angaben stehen im Block direkt unter „Die Signatur“. Das Logo liegt als bilder/logo-signatur.png daneben und ist zusätzlich in der Datei eingebettet. Die Kontaktdaten der Website stehen in src/config/site.ts und müssen hier von Hand nachgezogen werden.
